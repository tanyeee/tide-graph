# 日立 潮位グラフ

気象庁「潮位表 日立」の天文潮位予測を表示する、GitHub Pages向けの静的Webアプリです。

久慈大橋・榊橋の国土交通省10分水位も重ねて表示できます。河川水位の右軸は、表示中の潮位と水位の5〜95パーセンタイルが縦方向に合うよう自動調整します。時刻は移動しないため、汽水域に潮汐変動が伝わる時間差を波形から比較できます。

黄色の点は選択時刻、赤い破線と赤い点は現在時刻を示します。現在時刻の点から広がる白い波紋は、OSやブラウザで「視差効果を減らす」が有効な場合は停止します。

## ローカル表示

ES ModulesとJSONデータを読み込むため、`index.html`を直接開かずHTTPサーバーを使用します。

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザで <http://127.0.0.1:8000/> を開きます。

## テスト

外部依存はありません。Node.js 22以降で実行します。

```bash
npm test
```

## 潮位データの更新

日立の地点記号は `D1` です。気象庁が配布する年別固定長テキストを検証し、`data/` のJSONキャッシュへ変換します。

```bash
npm run update-data
```

年を明示する場合：

```bash
node scripts/update-tide-data.mjs --years 2026 2027
```

通常実行では当年を必須、翌年を任意として取得します。翌年分がまだ公開されていない場合も、当年分の更新は成功します。年跨ぎ表示のため前年データを1年分保持し、それより古い年別キャッシュは自動整理します。

GitHub Actionsの `Update tide data` workflowが毎月1日に同じ処理とテストを実行し、変更がある場合だけデータをcommitします。手動実行も可能です。

## 出典と注意事項

- 出典：[気象庁「潮位表 日立」](https://www.data.jma.go.jp/kaiyou/db/tide/suisan/suisan.php?stn=D1)
- 表示値は天文潮位の予測値であり、気象などの影響を受ける実測潮位とは異なります。
- 10分刻みの値は、気象庁の毎時潮位をアプリ内で直線補間しています。
- 潮名は[日本水路協会 MIRC「科学的な潮名の決め方」](https://www.mirc.jp/online/w/w-tide/knowledge/SN-det.html)に基づき、JST 0時の太陽・月の黄経差から判定しています。
- 河川水位は[久慈川水位ビューア](https://tanyeee.github.io/kuji-waterlevel/)が公開する国土交通省観測データを読み込みます。
- 潮位と河川水位は基準面が異なります。右軸の自動フィットは波形と時刻差を見やすくするための表示であり、絶対的な高さの比較には使用できません。
